Using the remote browser

Click anywhere on the stream first so keystrokes are forwarded. Everything you type goes to the remote Chrome, not to this page.

Ctrl+LFocus the address bar
Ctrl+TNew tab
Ctrl+RReload page
Ctrl+C / VCopy / paste (paste is supported)
F11Fullscreen this view (local)

Some local browser shortcuts (Ctrl+W, Ctrl+N) cannot be intercepted by a web page. Use the on-page buttons instead.
